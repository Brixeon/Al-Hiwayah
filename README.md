# Al-Hiwayah
Al-Hiwayah adalah platform web pembelajaran interaktif Bahasa Arab untuk siswa SD/MI Kelas II berbasis Kurikulum Merdeka &amp; Deep Learning. Website ini dirancang untuk membuat proses belajar Bahasa Arab menjadi menyenangkan, kontekstual, dan mudah dipahami melalui elemen gamifikasi dan aktivitas kreatif.
